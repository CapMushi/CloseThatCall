# Interview Master

Personal interview-prep knowledge base (see README.md for layout).

## Hard rules

- Never run git or GitHub operations (init, commit, push, PRs). Do not touch GitHub.
- Never generate CVs; the user provides them.

## Folder rules

Every folder that contains content files also has a `RULES.md`. Before creating or editing any file in a folder, read that folder's `RULES.md` and follow it. If a folder has content but no `RULES.md`, ask the user for the rules or propose them before writing.
