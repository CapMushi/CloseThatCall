# Domains

Background per industry domain — vocabulary, regulations, common systems/data types, typical pain points. One folder per domain, e.g.:

- `fintech/` — payments, ledgers, KYC/AML, fraud, regulatory (PCI-DSS, SOX)
- `healthcare/` — EHR systems, claims, HIPAA, HL7/FHIR
- `ecommerce/` — catalog, inventory, recommendations, checkout

Referenced by `project-stories/` rather than duplicated there.
